why Use Pytest?

When working in test automation ,  you need a  powerfull , easy  to use , and  scalable testing framwork, Pytest is the  best  choice  foe the following  reasons 

1, Simple and  Readable 
2, FEature Rich -  Includes Assertions, Fixtures , Parameterations and  plugins 
3, Scalable
4, Integration - friendly - works with Selenium, Api Testing, and ci/cd tools

2, What is  Pytest?

Pytest is a  Python testing framework used for :

1, Unit testing (testing individual  Functions)
2, API Testing (Validating API Responses)
3, UI Automation (With Selenium for web apps)
4,  End  to end Testing (Full  workflow testing  )


It follows a convention - based  approach 

-> Test files should  strat  with test_*.py
-> Test function should start with test_*
